# Mahi-Mahi 20-node GCP 120K point, 2026-09-16

Goal:
- Switch the GCP testbed from 10 nodes to 20 nodes.
- Run one 20-node, f=0 Mahi-Mahi point at 120K tx/s and compare it with existing 20-node baselines.

Testbed preparation:
- Kept the existing 10 stopped VMs.
- Created 10 additional VMs, 2 per configured region, from machine image `shortfin-noveldag-machine-image-20260916`.
- Avoided `fab create --nodes=4` because the Fabric create path counts active GCP instances and can over-create when existing instances are stopped.
- Final layout:
  - `asia-east1`: 4 VMs
  - `asia-southeast1`: 4 VMs
  - `europe-west1`: 4 VMs
  - `us-east1`: 4 VMs
  - `us-west1`: 4 VMs
- All VMs use 25GB `pd-ssd` disks.
- Remote binary/source commit verified on all 20 VMs: `2814bbc2552a067aa16851e8920491e35ce3ab75`.

Run configuration:
- Protocol: `mahi_mahi`
- Nodes: 20
- Faults: 0
- Rate: 120,000 tx/s
- Duration: 50s
- Benchmark delay: 20s
- Runs per point: 1

Result:

| Protocol | Input rate | Consensus TPS | Consensus latency | E2E TPS | E2E latency | Config hash |
| --- | ---: | ---: | ---: | ---: | ---: | --- |
| Mahi-Mahi | 120K | 110,181 | 3.990s | 108,061 | 5.014s | yes |

Comparison with existing 20-node f=0 120K baselines:

| Protocol | E2E TPS | E2E latency |
| --- | ---: | ---: |
| Narwhal/Tusk | 79,847 | 5.999s |
| Shortfin / NovelDAG legacy | 98,427 | 4.332s |
| Wahoo legacy | 108,905 | 2.921s |
| Mahi-Mahi current | 108,061 | 5.014s |

Sanity checks:
- Config hash verification passed.
- Log scan found no panic/fatal messages.
- No client missed-target warning appeared in the run summary or client logs.
- All 20 GCP VMs were confirmed `TERMINATED` after the run.

Interpretation:
- This first 20-node Mahi-Mahi point is valid and comparable to the existing 20-node baseline table.
- At 120K, Mahi-Mahi throughput is close to the legacy Wahoo point and above the legacy Shortfin/Narwhal points, but its latency is closer to Narwhal/Shortfin than to Wahoo.
- Because this is only one single-run point, use it as the anchor for a Mahi-Mahi 20-node curve rather than a final statistical claim.
